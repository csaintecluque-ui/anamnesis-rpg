# Propositions de Claude pour le jeu

Une proposition n'est canon qu'après validation de Cyril. Chaque élément vit dans le fichier de son thème, avec son statut :
- lieux : `docs/univers/lieux/gardebois.md` (validé), `docs/univers/lieux/gare-engloutie.md` (validé),
  `docs/univers/lieux/villes.md` (dix grandes villes, plan validé), `docs/univers/lieux/canopee.md` (détails à valider) ;
- personnages : `docs/univers/personnages/pnj.md` (validé) ;
- systèmes : `docs/gdd/`.

Les propositions qui n'ont pas d'autre fichier sont ci-dessous.

## Rejeté

Les propositions de la session 1 (Aubelac, le Phare des Échos, Ysolde, Corvin, Aldric, les Oublieux, les attributs Résonance et Grâce) sont **rejetées**. Elles ont été inventées avant la lecture du canon et faisaient doublon : « Résonance » est déjà un terme canon (Cristaux de Résonance, Résonance Fatale) ; « Corvin » rappelle trop le savant Corvan ; « Aldric » rappelle trop Aldara.
