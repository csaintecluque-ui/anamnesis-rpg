# Ton et sonorités

Sources et statuts : `docs/univers/sources.md`.

- **Épique et merveilleux**, avec un optimisme prudent : un monde dangereux mais beau. Dosage : 60 % aventure, 20 % émerveillement, 15 % émotion, 5 % humour. [E1]
- **Références tonales** : *Avatar, le dernier maître de l'air*, *Le Seigneur des Anneaux*, le Studio Ghibli, *Horizon Zero Dawn*. [E1]
- **Ce que le ton n'est pas** : ni grimdark, ni cynique, ni désespéré en permanence ; pas de violence gratuite ni d'horreur pure. [E1]
- **Public** : familial, 8 à 15 ans, « accessible à tous ». [E1] Pour le jeu : ennemis mis hors de combat, sans mort ni gore (`docs/univers/zones-floues.md`, point 19).
- **Neutralité morale** : aucune nation n'est entièrement bonne ou mauvaise ; pas de caricatures. [RES]
- **Sonorités des noms** :
  - Verdantis : douce (l, m, n, v, s ; « Lyra Cœur-de-Sève ») [N1] ;
  - Ferros : dure, martelée (« Markus Steelheart », « Gorim Tuefer ») [N2, E4] ;
  - Glacialis : gutturale [N6] ;
  - Zephyria : sifflée [N3] ;
  - Marisol : vocalique [N4] ;
  - Communion : apostrophes (« Kal'Sharash ») [N5].
